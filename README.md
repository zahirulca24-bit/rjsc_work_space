# RJSC Office Management Frontend V1

Internal frontend prototype for FAMES & R Chartered Accountants.

## Run on Windows
1. Install Node.js LTS.
2. Double-click `START.bat`.
3. Open http://localhost:3000

Or from VS Code terminal:
```powershell
npm install
npm run dev
```

## Current state
- Frontend only
- Mock/local data
- No fake API calls
- Ready for FastAPI + Neon + Google Drive integration

## Main screens
Dashboard, Clients, Work Register, New Work, Services & Fees, Fee Calculator, Documents, Checklist/Requisition, Working Papers, Transactions, Billing, Team, Reports, Settings.
